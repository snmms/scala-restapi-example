Contexto del problema
- tienda de productos tecnológicos
- información relacionada con productos, precios, categorías, stock y ventas. 
- Procesar correctamente estos datos es importante para encontrar productos disponibles, identificar aquellos con bajo stock, clasificar productos por categoría y analizar las ventas.

Importancia del filtrado de datos
- Buscar productos por categoría.
- Encontrar productos con stock bajo.
- Filtrar productos según su precio.
- Obtener productos disponibles.
- Analizar productos más vendidos.
- Agrupar productos por categoría.
- Ordenar productos según diferentes características.
